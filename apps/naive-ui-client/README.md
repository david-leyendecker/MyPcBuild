# MyPCBuild - Naive UI Client

This is the completely reimplemented UI for MyPCBuild using Naive UI v2.43.2.

## Features

- **Modern UI Framework**: Built with Naive UI v2.43.2
- **Theme Support**: Light/Dark mode toggle
- **Modern Layout**: App title bar with left-side navigation drawer
- **Icon System**: Consistent use of NIcon component from @vicons/ionicons5
- **3D Visualization**: Integrated 3D viewer with popout support
- **Responsive Design**: Mobile-friendly layouts using Naive UI grid system
- **No Custom CSS**: Leverages Naive UI theming and styling

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Technology Stack

- Vue 3.5.24
- Naive UI 2.43.2
- TypeScript
- Vite 7.2.4
- Pinia (state management)
- Vue Router 4.6.4
- Three.js (3D visualization)
- @vicons/ionicons5 (icons)
